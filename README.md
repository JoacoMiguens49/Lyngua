# Lyngua

App Lyngua

armar una app para aprender idiomas interactivamente escuchando musica

la idea es escuchar un tramo de una cancion, y tenes que escribir exactamente la letra de dicho tramo 
como para practicar escritura, listening, gramatica y ademas de aprender canciones en el proceso.

la idea seria dividir la cancion en tramos de 15, 20s, hasta completar la cancion entera (tipo logro).

LA APP VA A CONSUMIR LA SDK DE SPOTIFY PARA OS ANDROID/iOS

a medida que el usuario escribe la letra, cuando finalice se le indicaria un % de exito en su escritura, y se marcarian 
sus errores para ser corregidos.

El proceso deberia ser gradual, mediante "niveles"l, en el cual al principio de la app, las canciones sugeridas son más basicas,
y a medida que se avanza, incrementa dicha dificutal.

Se debe PODER FILTRAR POR GENERO musical acordemente.

Tambien debera solicitar que idiomas hablas (y en que nivel) y que idiomas QUERES PRACTICAR (y en que nivel) (básico-intermedio-avanzado)


Idealmente deberan haber varios modos de juego, por ahora SOLO el mencionado y una practica tipo Deathmath contra un bot regulado
que tarde X tiempo ++- un cierto % para hacerlo variante.
